Worst-case optimal joins in Hooray · 3

Every datom lives in several sorted indexes, so each access pattern is a lookup or a range scan. AVE answers: given an attribute and a value, which entities. AEV answers: given an attribute and an entity, what are the values. In Hooray every index is a nested sorted map. Keep that in mind: a nested map is a trie, and tries are exactly what worst-case optimal joins want.
