The triangle query as three stages

P1 = [?a :follows ?b]   P2 = [?b :follows ?c]   P3 = [?a :follows ?c]

On the star: rows with a = hub die in stage 2, because followees follow nobody. For each follower, stage 3 proposes from follows(a), which has one entry. The work stays linear.
