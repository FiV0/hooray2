# Slides: Worst-case optimal joins in Hooray

The slide deck for the talk on worst-case optimal joins in Hooray: a Datomic
recap, binary joins, the result set as a trie (depth first for Leapfrog
Triejoin, breadth first for Generic Join), the old `PrefixExtender` interface
and the `ExecPattern` + stages design that replaced it.

The deck is generated by `generate.py` and presented as a claude.ai Slides
artifact.

## Generating

Requires Python 3 and nothing beyond the standard library. From the repository root:

```sh
python3 slides/generate.py            # writes to slides/out/
python3 slides/generate.py some/dir   # or to another directory
```

This writes:

```text
slides/out/project/
├── deck.json          # deck index: title, slide order, sections, fonts
└── slides/
    ├── cover.html     # one file per slide
    ├── datoms.html
    └── ...
```

Slides that are no longer in the deck are removed from the output directory.
`slides/out/` is ignored by git.

## Slide format

The files follow the layout of the claude.ai "Slides" artifact type. Each
slide file contains exactly one `<section>` on a fixed 1920×1080 canvas, with
inline styles only (no classes, `<style>` blocks or scripts). Speaker notes
are the `<aside>` at the end of each section. Opened directly in a browser,
the files are not a usable deck; the Slides viewer provides layout, Present
mode and PDF/PowerPoint export.

## Editing

All content lives in `generate.py`:

- `ORDER` lists the slide ids in deck order. Footer page numbers follow it.
- Each slide is one `slides["<id>"] = section(...)` block. The last argument
  of `section` is the speaker notes.
- Helpers such as `head`, `code`, `p`, `table`, `row`, `col` and `tree` build
  the markup. Code snippets are written as plain text and escaped by `code`.
- The deck's sections and fonts are set in the `deck` map at the end of the
  file.

Treat `generate.py` as the source of truth. Edits made in the claude.ai slide
editor are overwritten the next time the generated files are published.

## Publishing

The deck is published with the Artifact tool in Claude Code. After
generating, ask Claude to publish the files to the existing deck, for example:

> Publish slides/out/project to the slides deck at <deck URL>.

Claude publishes `project/deck.json` and the changed `project/slides/*.html`
files with `slides/out` as the root. A slide that was removed from `ORDER`
also has to be removed from the published deck.
